
# 📊 TP1 — Statistiques Descriptives avec Python

## 📌 Description
Travaux pratiques sur les statistiques descriptives réalisés dans le cadre 
du cours de Data Science à ENICarthage.

## 🎯 Objectifs
- Calculer les mesures de tendance centrale (moyenne, médiane, mode)
- Calculer les mesures de dispersion (variance, écart-type)
- Visualiser les distributions avec des graphiques
- Analyser un dataset réel avec Python et Pandas

## 📁 Contenu
- `TP1_correction.ipynb` — Notebook Jupyter avec les solutions complètes
- `TP1_Statistiques descriptives avec python.pdf` — Énoncé du TP
- `Notes (8).xlsx` — Dataset utilisé pour l'analyse

- Jupyter Notebook
